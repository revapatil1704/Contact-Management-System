# Contact-Management-System
This project is developed using Java and File Handling concepts. The Contact Management System allows users to store and manage contact details easily. Users can: Add contacts, View contacts, Update contacts, Delete contacts, Save contacts into a file Load saved contacts automatically.The project uses a text file  for permanent data storage.



Technologies Used:

Java
Java IO (File Handling)
ArrayList
Scanner Class
Eclipse 


Concepts Used:
Object Oriented Programming (OOP)
Classes and Objects
ArrayList
File Handling
Exception Handling
Menu Driven Program


Features:

Add Contact:-
User can add new contact details.

View Contacts:-
Displays all saved contacts.

Update Contact:-
User can modify existing contact details.

Delete Contact:-
Removes contact from list.

Save Contacts:-
Stores contact details into text file.

Load Contacts:-
Reads contact details from file automatically when program starts.
